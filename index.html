Snake Arena 웹 게임

완성, 계속 다듬는 중

Snake.io처럼 마우스로 뱀을 움직여 먹이를 먹고 커지는 브라우저 게임입니다. HTML 파일 하나에 캔버스 그리기, 리더보드와 미니맵을 담았고, Supabase Realtime으로 친구들과 실시간 대결할 수 있습니다.

조작 방법
🖱️ PC: 마우스로 방향 조종, 클릭하거나 스페이스바를 누르고 있으면 부스트
📱 모바일: 화면을 터치해 방향 조종, 왼쪽 아래 BOOST 버튼으로 가속
🏁 규칙: 먹이를 먹으면 길어지고, 머리가 다른 뱀 몸이나 빨간 테두리에 닿으면 끝. 같은 링크로 들어온 친구들과 실시간으로 대결해요(봇 없음).

배운 점 설치 없이 링크 하나로 공유하려면 GitHub Pages처럼 공개된 주소에 올려야 한다는 것.
